这是一份自用的命令备课本，忘记某个命令干什么用的时候来翻这里。
记不住那么多命令的话，先背熟第一节的”名字都是缩写”，剩下的随用随查。

0. 命令名都是缩写，记住了就不难

命令 英文全称 含义
ls list 列出文件
cd change directory 切换目录
pwd print working directory 打印当前目录
cp copy 复制
mv move 移动/重命名
rm remove 删除
mkdir make directory 创建目录
cat catenate 拼接/查看
df disk free 磁盘剩余
du disk usage 磁盘占用
ps process status 进程状态
grep global regular expression print 全局正则搜索

6. 权限管理

ls -l 输出第一列 drwxr-xr-x 的意思是：d(目录) rwx(所有者) rwx(所属组) rwx(其他人)，r=读 w=写 x=执行。

⚠️ 注意：从 Windows 拖文件进 WSL 目录会带出 xxx:Zone.Identifier 这种垃圾文件，提交前记得删掉：find . -name "*:Zone.Identifier" -delete

14. 终端快捷键（比鼠标快）

按键 作用
Tab 自动补全命令/路径（按两下列出候选）
Ctrl + C 结束当前命令
Ctrl + Z 挂起当前命令（用 fg 调回）
Ctrl + L 清屏
Ctrl + A / Ctrl + E 光标跳到行首 / 行尾
Ctrl + U / Ctrl + W 删除光标前全部 / 删除前一个词
Ctrl + R 搜索历史命令（再按 Ctrl+R 向下翻）
↑ / ↓ 上一条 / 下一条历史命令

15. 忘了命令怎么办

一句话总结：cd 去对地方 → ls 看清有啥 → cat/less 看内容 → 改完 git add . && git commit && git push → 博客自动更新。剩下 99% 的命令都能 /mnt/c、sudo apt install、man 三条路解决。
