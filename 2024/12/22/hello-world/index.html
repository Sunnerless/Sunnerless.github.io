这是博客重新搭建后的第一篇测试文章，说明一切正常。

以后怎么写文章

  1. 在项目根目录执行：hexo new post "文章标题"
  2. 编辑 source/_posts/文章标题.md（写 Markdown 就行）
  3. 提交并推送：git add . && git commit -m "新文章" && git push
  4. 等 1~2 分钟，GitHub Actions 会自动构建、发布到 https://sunnerless.github.io

也可以本地预览：npm run server，然后浏览器打开 http://localhost:4000
